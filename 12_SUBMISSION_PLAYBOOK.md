# Devpost story structure

## Inspiration

Tell the moment, not a generic market statistic.

## What it does

Explain:
skin snapshot → candidate evidence → deterministic compare → VTO proof → receipt.

## How we built it

Focus on:
- YouCam Skin Analysis
- YouCam Makeup VTO
- adapter architecture
- deterministic decision engine
- evidence/provenance

## Challenges

Good challenges:
- asynchronous provider workflow
- separating medical-adjacent claims from decision support
- unknown evidence handling
- demo reliability without pretending replay is live
- mapping products into VTO-compatible visual proof

## Accomplishments

Credible:
- two meaningful YouCam capabilities in one coherent decision loop
- deterministic explainable ranking
- abstention
- evidence provenance
- Decision Receipt
- Judge Mode
- privacy/failure handling

## What we learned

Focus on:
API reality, evidence design, uncertainty, responsible beauty AI.

## What's next

- retailer catalog integrations
- better product metadata
- controlled user studies
- validated recommendation heuristics
- more makeup categories

Do not promise medical diagnosis.
