# Pre-Submission Checklist

## Product
- [ ] First screen communicates the moment in <10 seconds
- [ ] Core flow is <=6 intentional actions in sample mode
- [ ] Skin state changes ranking
- [ ] VTO follows ranking
- [ ] Decision Receipt visible

## YouCam
- [ ] Live Skin Analysis verified
- [ ] Live Makeup VTO verified
- [ ] API key server-side
- [ ] Timeouts/retries bounded
- [ ] Fixtures recorded from real calls
- [ ] Replay clearly labeled

## Integrity
- [ ] No diagnosis
- [ ] No guaranteed acne claims
- [ ] No unknown→safe
- [ ] Product facts sourced
- [ ] No fabricated KPI
- [ ] Limitations documented

## Engineering
- [ ] lint
- [ ] typecheck
- [ ] unit
- [ ] property
- [ ] integration fixture
- [ ] e2e replay
- [ ] secret scan
- [ ] dependency audit
- [ ] production build

## UX
- [ ] mobile
- [ ] desktop
- [ ] keyboard
- [ ] reduced motion
- [ ] error states
- [ ] loading states
- [ ] accessible labels

## Submission
- [ ] repo public or judge access configured
- [ ] README complete
- [ ] deployment works without login
- [ ] screenshots
- [ ] 1–3 min video
- [ ] YouCam APIs explained
- [ ] Judge Mode documented
- [ ] no copyrighted music
